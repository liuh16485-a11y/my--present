# 🎁 礼品项目 (Gift Center Studio)

本项目是一个专为礼品选型采购与市场营销宣传打造的轻量级、全功能 Web 工作台。所有项目文件均统一存储在 `C:\文件\谷歌AI\个人\礼品` 目录下。

---

## 🌟 核心功能一览

### 1. 🎨 宣传图生成 (Marketing Poster Studio)
- **多模态输入支持**：
  - **基于已有礼品一键生成**：在礼品库卡片上点击「生成宣传图」，自动将该礼品的图文、价格与卖点填入生成器。
  - **自定义图文生成**：支持随时输入自定义标题、宣传标语、活动徽章、详细卖点、价格与品牌名。
  - **配图/纯文字双模式**：
    - 上传/选择产品图片：自动进行主体悬浮渲染、立体展台排版与漫反射光晕。
    - 纯文字模式：若无产品图，智能自动生成极具视觉冲击力的 3D 礼盒艺术勋章与几何排版。
- **最少保证两种基本设计风格（共提供 8 种高品质设计款式）**：
  - **商务风格（4款变体）**：
    - `尊贵黑金版`：黑曜石底纹、金属拉丝框线、典雅奢华质感。
    - `现代极简白`：银灰高级留白、瑞士国际主义杂志排版、通透克制。
    - `深邃藏蓝格调`：皇家藏青搭配香槟金，沉稳大气、尊贵致礼。
    - `雅致墨玉典藏`：东方国韵墨绿色泽配烫金，高端商务宴请优选。
  - **活力风格（4款变体）**：
    - `暖阳落日橙`：阳光暖橙与珊瑚霞光渐变，充满生机与温暖。
    - `赛博极光潮酷`：霓虹紫电与数码青蓝渐变，适合潮流科技新品。
    - `盛典欢庆红`：宝石正红与金辉粒子，节日迎春、企业开门红庆典。
    - `薄荷清新蓝绿`：解压清爽、自然元气、果礼轻食必备。
- **多比例画幅支持**：
  - `9:16`：手机全屏长海报 / 微信朋友圈 / 竖版故事（1080 × 1920 像素超清）
  - `3:4`：小红书图文 / 电商详情卡片（1200 × 1600 像素超清）
  - `1:1`：社交头像 / 正方形商品橱窗（1200 × 1200 像素超清）
- **挑选与下载能力**：
  - 同屏画廊多款并排展示对比与挑选。
  - 点击任意海报可进入全屏大图无损检视。
  - 支持单张超清无损 PNG 下载。
  - 支持**一键打包下载全套 ZIP 压缩包**（内置 JSZip 异步处理引擎）。

### 2. 📦 礼品挑选与管理 (Gift Catalog & Selection)
- **礼品库展示与检索**：
  - 网格卡片直观展示：**名称**、**图片**、**描述**、**分类**、**卖点标签**、**单价/估值**。
  - 支持模糊关键词搜索（匹配名称、标签、描述）与多分类联动筛选。
- **多选数量操作**：
  - 每个礼品卡片配备步进加减器 `[-] [数量] [+]`，支持直接输入或加减。
  - 支持不同礼品选择各自的数量（如礼品 A 选 5 件、礼品 B 选 10 件）。
- **选礼清单抽屉（Cart & Order Manifest）**：
  - 实时统计选中的礼品总品类数与总件数。
  - 侧边抽屉一览已选明细与小计。
  - **一键复制清单文本**：自动整理成规整文本格式，便于直接粘贴至微信群、邮件或采购申报。
  - **一键导出 CSV 电子表格**：直接下载 UTF-8 编码的表格文件，方便在 Excel / WPS 中开启与编辑。
  - **一键清空与重置**。
- **完整的增删改查 (CRUD)**：
  - **新增礼品**：弹窗录入名称、图片（支持上传本地图片文件或选择内置精选图样）、分类、单价、描述与标签。
  - **编辑礼品**：随时修改已有礼品的任何属性。
  - **删除礼品**：安全确认后删除，同时自动更新选择清单。
  - **本地数据持久化**：使用浏览器 `localStorage` 自动持久化存储，关闭页面不丢失；提供「恢复预设」按钮随时还原示例库。

## 🚀 启动与使用方式

### 方式一：双击启动脚本（推荐）
直接双击运行目录下的 `启动.bat`：
1. 脚本将自动调用 Python 启动本地 Web 服务器；
2. 自动唤起系统浏览器并访问 `http://127.0.0.1:8085`；
3. 控制台同时输出局域网 IP，便于手机在同一 Wi-Fi 下扫码或直接打开访问。

### 方式二：命令行启动
打开 PowerShell 或 CMD：
```bash
cd "C:\文件\谷歌AI\个人\礼品"
python server.py
```

### 方式三：免服务器直接双击
直接用 Chrome、Edge 等现代浏览器双击打开 `index.html` 即可离线使用全部挑选与海报生成功能。
